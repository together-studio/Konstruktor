# Конструктор питания

Одностраничный сайт для клиентов: расчёт калорий и БЖУ и конструктор рациона на день.
Основа — таблица «Конструктор питания» (вкладки «Женщина», «Мужчина», «Конструктор — Женщина»,
«База продуктов», «Списки конструктора», «ПП-рецепты»).

Весь сайт — один файл `index.html`: работает без интернета и сервера, данные клиента
сохраняются в его браузере.

Расчёт ориентировочный. При заболеваниях, беременности и ГВ — сначала консультация врача.
